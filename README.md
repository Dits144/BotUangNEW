# BotUang Dashboard

Modern Next.js dashboard for BotUang WhatsApp finance bot.

## Local Development

```bash
npm install
npm run dev
```

## Vercel

Use Node.js 22 and set these environment variables:

```env
BOT_API_URL=https://api.dashboardits.tech
BOT_API_TOKEN=your_bot_api_token
```

The production dashboard domain can be pointed to `dashboardits.tech`.
